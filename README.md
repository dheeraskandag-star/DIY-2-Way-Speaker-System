# DIY-2-Way-Speaker-System

It is a small 2-Way bookshelf speaker. It has a 20W tweeter and a 40W woofer. It is a relatively simple build.
I've always been interested in audio and electronics, so I decided to build a pair of 2-way bookshelf speakers from scratch. My goal was to learn about speaker design and crossovers, while creating a speaker system I could use every day.One of the main problem/challenges which I had was sourcing quality components.Since this is my first build, I decided to go with moderate quality components.
